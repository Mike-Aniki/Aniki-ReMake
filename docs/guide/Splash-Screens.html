Splash Screens

The Aniki game launch Splash Screen displays an image or video while a game is starting.

You can use one global splash for everything, or choose different media depending on the game, platform or source.

Open Splash Screen settings

The complete Splash Screen configuration is in Aniki Helper Desktop settings.

  1. Open Playnite in Desktop mode.
  2. Click the Playnite icon in the top-left corner.
  3. Select Add-ons... or press F9.
  4. Open Extension settings → Generic.
  5. Select Aniki Helper.
  6. Open Exclusive Features at the top.
  7. Select Splash screen on the left.

First-time setup

Use this if you want to enable the feature without creating a complicated priority system.

  1. Enable Game launch screen.
  2. Leave the selection mode on the normal/default priority mode unless you already know you want something else.
  3. Open Global splash.
  4. Click Add local files.
  5. Select an image or video.
  6. Close the splash manager.
  7. Set a Minimum display duration.
  8. Save the Aniki Helper settings.
  9. Launch a game from Fullscreen to test it.

If no more specific splash is selected, the global splash is used as the fallback.

Add more than one splash

The splash manager can contain multiple files.

  1. Open the relevant Global, Source, Platform or Game splash manager.
  2. Click Add local files.
  3. Add several images/videos.

By default Aniki can choose between the files.

If you want one file to always be used:

  1. Select it.
  2. Choose Always use this image.

To return to random choice, use Return to random choice.

Choose which splash is displayed

The Splash selection mode decides which source is tried first.

Priority modes can fall back to other available sources.

Game priority

Use this when game-specific content should be preferred.

Aniki can fall back through other available sources when the preferred game content is unavailable.

Platform priority

Use this when platform identity should be preferred.

For example, games assigned to the same Playnite platform can share a platform splash.

Source priority

Use this when the Playnite source should be preferred.

This is useful if you want different launch media for sources such as Steam, GOG or Epic.

Global only

Always use the global splash.

No source/platform/game-specific splash is used.

Custom priority

Lets you define your own order using:

  • Game custom
  • Game background
  • Platform
  • Source
  • Global
  • None

Configure a platform splash

  1. Open the Splash Screen settings.
  2. Find Splash management.
  3. Select Splashes by platform.
  4. Choose the Playnite platform.
  5. Add one or more files.
  6. Close the manager.
  7. Use a selection mode where Platform can be chosen before the global fallback.
  8. Save.
  9. Launch a game assigned to that platform and test it.

The game must actually have that Playnite platform assigned.

Configure a source splash

  1. Open Splashes by source.
  2. Choose the source.
  3. Add the media.
  4. Close the manager.
  5. Use a selection mode where Source is part of the priority.
  6. Save and test a game from that source.

Configure a splash for one game

Game-specific splash management is available from Playnite Desktop.

  1. Find the game in the Playnite Desktop Library.
  2. Right-click it.
  3. Open Aniki Helper.
  4. Open Splash Screen.
  5. Select Manage splash screens.
  6. Add the media you want.
  7. Close the manager.

Use Game priority or a suitable custom priority if you want game-specific media to be preferred.

Change the display duration for all games

The global timer is in:

Aniki Helper → Exclusive Features → Splash screen → Global timers

  1. Set Minimum display duration.
  2. Save.
  3. Test a normal game.

This value applies by default to every game that does not have its own timer override.

Change the duration for one game

A per-game timer is useful when one game takes longer or shorter to start than the rest of your library.

Desktop

  1. Right-click the game.
  2. Open Aniki Helper → Splash Screen.
  3. Select Set minimum timer for this game.
  4. Enter the duration in seconds.
  5. Confirm.

Fullscreen

  1. Select the game in the Library.
  2. Press Y to open Game Options.
  3. Open Extensions → Aniki Helper → Splash Screen.
  4. Open Set minimum timer for this game.
  5. Choose one of the available presets.

Fullscreen offers preset values from seconds up to several minutes.

The per-game timer takes priority over the global minimum duration.

Reset a game's custom duration

Fullscreen or Desktop

Open the same game's:

Aniki Helper → Splash Screen

Then select:

Reset minimum timer for this game

The game returns to the normal global timer.

Can I set a timer for an entire platform?

The current custom duration override is per game.

Platform/source settings control the splash media selection, not one shared custom minimum-duration override.

If several games need longer launch times, set the timer on those games individually.

Let Aniki wait for the actual game window

Enable:

Auto-detect when the game window is ready

When enabled, Aniki Helper keeps the splash visible until the real game window is detected.

This is useful when game launch time varies.

Per-game custom minimum timers still take priority.

Automatic close safety timer

The Automatic close safety timer prevents a splash from staying visible forever.

If the game never reaches the foreground as expected, Aniki closes the splash after this maximum wait.

Use it as a safety fallback, not as your normal minimum display duration.

Show the game logo

  1. Enable Show game logo on the splash screen.
  2. Select Logo position.
  3. Choose the placement you prefer.
  4. Save and test.

Available positions cover left, center and right areas at the top, middle and bottom.

Video splash sound

If you use video splashes:

  1. Enable splash video sound if you want audio.
  2. Adjust Video volume.
  3. Save.

This setting affects video splashes only.

A video ends before the Splash Screen timer

Choose When a splash video ends early.

You can:

  • show the game background for the remaining time;
  • keep the last video frame.

Choose whichever looks better with your launch videos.

Pause UniPlaySong during the splash

If UniPlaySong is installed:

  1. Enable Pause UniPlaySong while splash screen is visible.
  2. Save.

Aniki pauses the background music while the launch splash is visible, then resumes it afterward.

Troubleshooting

The splash disappears too quickly

Check:

  1. the global Minimum display duration;
  2. whether that game has a custom timer;
  3. Auto-detect game window.

The splash stays too long

Check:

  1. whether the game has a long per-game timer;
  2. your global minimum;
  3. the auto-detection behavior;
  4. the safety timer.

The wrong splash is displayed

Review your Splash selection mode and the available Game/Platform/Source/Global media.

One game behaves differently

Reset its per-game timer and check whether it also has a game-specific splash.
