Profile & Startup

This page covers username, avatar, login screen and the screen Aniki opens on startup.

Change your username

  1. Open Aniki Fullscreen.
  2. Press Start / Menu.
  3. Open Settings → Customization.
  4. Open Appearance.
  5. Select Choose your username.
  6. Enter the name you want.

The profile name is used throughout the Aniki interface.

Change the built-in avatar

  1. Open Settings → Customization → Appearance.
  2. Select Choose avatar.
  3. Pick one of the built-in avatars.

The built-in avatar is the fallback when no higher-priority profile image is available.

Use your own custom profile picture

If you use the Extra Metadata tools, Aniki can use the profile picture stored by that extension instead of a built-in avatar.

In Playnite Desktop mode:

  1. Open the Playnite main menu.
  2. Open Extensions.
  3. Open the Extra Metadata / Extra Metadata Tools menu.
  4. Open its Themes actions.
  5. Choose Set profile picture.
  6. Select your image.

After the profile picture is saved, Aniki uses it automatically.

Avatar priority is:

  1. Steam profile avatar, if Use Steam profile avatar is enabled and a Steam avatar is available.
  2. Extra Metadata profile picture.
  3. Built-in Aniki avatar.

Advanced: replace one of the built-in avatar files

Using Extra Metadata → Set profile picture is the preferred custom-avatar method because it survives theme updates.

If you specifically want to replace one of Aniki's built-in avatar files:

  1. Open Playnite Desktop.
  2. Press F9.
  3. Open Installed → Themes Fullscreen → Aniki ReMake.
  4. Click Installation Folder.
  5. Open Themes Option\3.Avatar.
  6. Replace the PNG you want to override while keeping the same filename.
Theme updates can overwrite files inside the theme folder. Keep a backup if you use this method.

Use your Steam profile avatar

  1. Make sure Steam is connected in Aniki Helper.
  2. Open Customization → Appearance.
  3. Enable Use Steam profile avatar.

If the Steam avatar is unavailable, Aniki falls back to the normal avatar priority.

See Steam for the connection setup.

Change the login screen background

  1. Open Customization → Appearance.
  2. Select Choose login screen background.
  3. Pick the background you want.
  4. Return to the interface.

Enable or disable the login screen

  1. Open Customization → Appearance.
  2. Find Show login screen on startup.
  3. Enable or disable it.

When disabled, Aniki goes directly to the selected startup destination.

Choose Hub or Library as the startup destination

This setting is managed by Aniki Helper.

Desktop method

  1. Open Playnite Desktop.
  2. Press F9.
  3. Open Extension settings → Generic → Aniki Helper.
  4. Open Theme features.
  5. Select Startup & Hub.
  6. Enable Open Hub on startup to start on the Hub.
  7. Disable it to start directly on the Library.
  8. Save.

Fullscreen method

The controller-friendly Aniki Helper settings also expose the Hub startup switch.

  1. Press Start / Menu.
  2. Open Settings → Customization.
  3. Select Aniki Helper Settings.
  4. Find Open Hub on startup.
  5. Change it.

Hide Playnite's normal game status screen

Aniki's launch Splash Screen and Playnite's normal game-status screen are two different things.

If you do not want Playnite's normal status screen to appear around game launches:

  1. Open Settings → Customization → Appearance.
  2. Find Hide Playnite game status screen.
  3. Enable it.

This does not disable Aniki Helper's own game launch Splash Screen.

Configure startup, shutdown and event sounds

These options are in Aniki Helper Desktop settings.

  1. Open Playnite Desktop.
  2. Press F9.
  3. Open Extension settings → Generic → Aniki Helper.
  4. Open Theme features.
  5. Select Sounds & Sequences.

From here you can:

  • enable/disable the Startup sequence;
  • enable/disable the Shutdown sequence;
  • enable/disable Event sounds for events such as game launch, Playnite start/exit and library updates.

If you enable Aniki Helper event sounds and another plugin also plays the same UI/event sounds, disable one of them to avoid duplicate audio.

Run the Initial Setup assistant again

If you want to re-choose several profile/startup/interface settings together:

  1. Press Start / Menu.
  2. Select Extras.
  3. Select Relaunch setup assistant.

See First Setup Assistant.
