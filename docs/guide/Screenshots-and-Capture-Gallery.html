Screenshots & Capture Gallery

Aniki Helper can read screenshots and video captures from a supported screenshot add-on and expose them in the Capture Gallery, Hub and compatible Aniki views.

You only need one screenshot provider.

First-time setup

If you just want the Capture Gallery working, follow this sequence first. The sections below explain each step and the advanced folder options in more detail.

  1. Install one screenshot provider: use Screenshots Visualizer or Screenshot Utilities. If you use Screenshot Utilities, install its Local Provider when required.
  2. Configure the screenshot folders in that provider: open its own settings and point it to the folders where Steam, emulators or other applications save your captures.
  3. Check the provider first: make sure the provider itself can see your screenshots before configuring Aniki.
  4. Select the same provider in Aniki Helper: open Aniki Helper → Theme features → Gallery & achievements and choose it under Screenshot provider.
  5. Generate Aniki thumbnails: in the same page, open Media thumbnails and run Generate thumbnails.
  6. Test the result: switch to Fullscreen, press Start / Menu → Extras → Capture Gallery.
If the Capture Gallery now shows your media, the basic setup is complete. Continue below only if you need multiple folders, per-game paths, refresh tools or troubleshooting.

Choose a screenshot provider

Supported choices are:

  • Screenshots Visualizer
  • Screenshot Utilities

If you use Screenshot Utilities, Aniki's current setup uses Screenshot Utilities - Local Provider.

If you selected a provider during the First Setup Assistant, the required add-ons may already be installed.

Install a provider manually

  1. Open Playnite Desktop.
  2. Press F9.
  3. Open Browse → Generic.
  4. Search for your chosen screenshot add-on.
  5. Install it.
  6. If you chose Screenshot Utilities, install its Local Provider when required.
  7. Click Save.
  8. Restart Playnite if requested.

Configure screenshot folders in the provider first

Aniki Helper does not decide where Steam, emulators or other programs store screenshots.

Configure those folders in the screenshot add-on itself.

  1. Open Playnite Desktop.
  2. Press F9.
  3. Open Extension settings → Generic.
  4. Select your screenshot provider.
  5. Configure the folders containing your screenshots/captures.
  6. Save.

Screenshots Visualizer — useful folder options

If you use Screenshots Visualizer, it supports scanning multiple screenshot folders.

Depending on your library, you can use:

  • automatically configured launcher screenshot folders;
  • a global screenshot path;
  • per-game folders;
  • multiple folders for special cases;
  • subfolder scanning where appropriate.

Global path for per-game folders

If all screenshots live under one common folder, configure Screenshots Visualizer's Global screenshot path.

When your folder structure uses the game name, use the path variables offered by the plugin (for example {Name} where appropriate).

Example concept:

D:\Screenshots\{Name}

The exact path must match your own screenshot folder structure.

Add an extra folder for one game

Use the per-game folder configuration in Screenshots Visualizer when one game stores screenshots somewhere different from the global setup.

Configure the provider until the provider itself can see your screenshots. Only then configure Aniki Helper.

Tell Aniki Helper which provider to use

  1. Open Playnite Desktop.
  2. Press F9.
  3. Open Extension settings → Generic → Aniki Helper.
  4. Open Theme features.
  5. Select Gallery & achievements.
  6. Choose your Screenshot provider.
  7. Save.

Generate Aniki thumbnails

Aniki Helper generates optimized thumbnails so Fullscreen does not need to load every original full-size image while you browse.

  1. Stay in Aniki Helper → Theme features → Gallery & achievements.
  2. Find Media thumbnails.
  3. Click Generate thumbnails.
  4. Wait for the scan to finish.

The first generation can take time on a large capture library. Later navigation should be faster.

Open Capture Gallery

From Aniki Fullscreen:

  1. Press Start / Menu.
  2. Select Extras.
  3. Select Capture Gallery.

The Hub can also expose recent captures depending on your configuration.

Refresh one game's media

If only one game's gallery is wrong:

Fullscreen

  1. Select the game.
  2. Press Y.
  3. Open Extensions → Aniki Helper.
  4. Open Media Gallery.
  5. Run the thumbnail/media refresh action.

Desktop

  1. Right-click the game.
  2. Open Aniki Helper → Media Gallery.
  3. Run the refresh/thumbnail action.

Captures do not appear

Check in this order:

  1. Can the screenshot provider itself see the files?
  2. Is the correct provider selected in Aniki Helper?
  3. Are the screenshot paths correct?
  4. If using Screenshot Utilities, is the Local Provider installed/configured?
  5. Have Aniki thumbnails been generated?
  6. Do the actual screenshot/video files still exist?

Fix provider-folder problems before troubleshooting the Aniki Gallery.
