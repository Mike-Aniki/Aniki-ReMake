Steam

Aniki Helper uses one Steam connection for its integrated Steam features.

The same session can power Friends, Store, wishlist and personalized recommendations.

No Steam Web API key is required for the current unified connection.

Open Steam settings

  1. Open Playnite Desktop.
  2. Press F9.
  3. Open Extension settings → Generic → Aniki Helper.
  4. Select the Steam tab.

The left-side pages are:

  • Account
  • Friends
  • Store
  • Updates
  • Current players

Connect your Steam account

  1. Open Steam → Account.
  2. Click Connect to Steam.
  3. The official Steam sign-in page opens.
  4. Sign in normally.
  5. Wait for the window to close/return.
  6. Confirm Aniki Helper shows Connected to Steam.
  7. Use Check connection if you want to verify the session.
  8. Save.

Your friends list does not need to be made public for this connection.

Steam is connected but features say the session is missing

  1. Open Steam → Account.
  2. Click Check connection.
  3. If the session still cannot be refreshed, use Reconnect to Steam or disconnect/connect again.

Steam login keeps refreshing

Aniki Helper includes a Playnite web-cache repair action.

  1. Open Steam → Account.
  2. Find the section for the Steam login repeatedly refreshing.
  3. Select Clear web cache and restart.
  4. Confirm the restart.
  5. Sign in to browser-based integrations again if required.
  6. Connect Steam again.

This clears Playnite's shared browser cache, so use it only when the login flow is actually broken.

Enable Steam Friends

  1. Open Steam → Friends.
  2. Enable Steam Friends integration.
  3. Decide whether to show offline friends.
  4. Choose which friend notifications you want.
  5. Save.

The theme can prioritize in-game/online friends and optionally show offline friends.

Show friends who played a game

Aniki uses a local cache for this Details feature.

  1. Open Steam → Friends.
  2. Find Friends played games.
  3. Click Refresh friends played games.
  4. Wait for the scan to finish.
  5. Save.

You do not need to run this every time you start Playnite.

Refresh it when the Details information is missing or clearly outdated.

Configure Steam Store

  1. Open Steam → Store.
  2. Enable Steam Store.
  3. Choose the Store language.
  4. Choose the Store country.
  5. Save.

The country affects displayed regional prices and currency.

When Store integration is disabled, the Store button/sections are hidden from the theme.

Enable Steam update information

  1. Open Steam → Updates.
  2. Enable update check.
  3. Run the full-library/initial cache scan if offered.
  4. Wait for it to finish.
  5. Save.

Pre-filling the cache helps Aniki avoid waiting for update information to build only as you browse.

Enable current player counts

  1. Open Steam → Current players.
  2. Enable player count.
  3. Save.

Disable it if you do not care about live player data.

Open Steam features in Fullscreen

Depending on your Aniki setup, Steam pages can appear in:

  • Quick Access;
  • the Hub;
  • the Hub Features & Apps page.

If a Steam page says authentication is required, return to Desktop mode and check Steam → Account first.
