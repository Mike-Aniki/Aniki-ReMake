HOME IMAGE OVERRIDES
====================

The Home page works immediately even if this folder contains no PNG files.
It uses the current images from the Aniki ReMake GitHub repository as fallbacks.

If you want to change a Home image WITHOUT editing HTML, simply add one of these
files to this folder:

logo.png
  Replaces the Aniki ReMake logo shown in the Home hero.

hero.png
  Replaces the large Home preview image.

welcome-hub.png
  Replaces the first large image in "Discover Aniki".

achievements.png
  Replaces the Achievements & Media showcase image.

game-details.png
  Replaces the Game Details showcase image.

Recommended:
- PNG or JPG converted/renamed to PNG
- 16:9 for hero / showcase images
- transparent PNG is fine for logo.png

Final location on GitHub:
docs/guide/assets/home/
