Keyboard, Mouse & Web Browser

Aniki Helper includes controller-oriented tools for Windows interaction outside normal Playnite navigation:

  • virtual keyboard;
  • Gamepad Mouse;
  • Aniki Web Browser.

Open Keyboard & Mouse settings

  1. Open Playnite Desktop.
  2. Press F9.
  3. Open Extension settings → Generic → Aniki Helper.
  4. Open Exclusive Features.
  5. Select Keyboard & mouse.

Configure the virtual keyboard

Choose the keyboard provider.

Aniki Keyboard

Uses Aniki Helper's own controller-friendly keyboard.

Windows Keyboard

Uses the Windows keyboard.

If you use the Windows provider, configure your preferred Windows keyboard layout first.

Choose the keyboard shortcut

Available direct shortcuts include:

  • Hold LS + RS
  • Back / Select / View + X
  • Guide + X
  • Disabled

The hold shortcut uses a short hold delay so it is not triggered by a normal stick click.

Guide combinations can be intercepted by Windows or other software.

Open the keyboard

While Playnite Fullscreen is running:

  1. Use your configured direct shortcut; or
  2. open it from the Aniki Overlay when available.

Use the controller to type, then close the keyboard when finished.

Configure Gamepad Mouse

In the same Keyboard & mouse page:

  1. choose the Gamepad Mouse activation shortcut;
  2. save.

Available activation shortcuts include:

  • Hold Back + RS
  • Hold Start + LS
  • Hold Guide + Y
  • Disabled

Gamepad Mouse controls

When enabled:

  • Right Stick — move the pointer
  • Left Stick — fast scroll
  • A — left click
  • X — right click
  • LT / RT — precise scrolling
  • Hold A + move Right Stick — drag and drop

Use your configured hold shortcut again to disable Gamepad Mouse.

Open Aniki Web Browser

From Fullscreen:

  1. Press Start / Menu.
  2. Select Extras.
  3. Select Aniki Web Browser.

The browser opens on its controller-friendly Home page.

Browser controls

The browser can use:

  • D-pad / Left Stick — navigate
  • Right Stick — cursor
  • A — select/click
  • X — keyboard
  • LB — previous page
  • RB — next page
  • B — back/home behavior
  • View — close web view
  • Y — address/search
  • Start — enter/confirm

The exact shortcut legend is also displayed by the browser.

Add Fullscreen favorites

Favorites are managed from Desktop Aniki Helper settings.

  1. Open Playnite Desktop.
  2. Press F9.
  3. Open Extension settings → Generic → Aniki Helper.
  4. Open Exclusive Features → Web browser.
  5. Under Fullscreen favorites, enter a name.
  6. Enter an http:// or https:// address.
  7. Click Add favorite.
  8. Reorder favorites if needed.
  9. Save.

The favorites appear as cards the next time the browser Home page opens.

Clear only the browser cache

If a site displays incorrectly:

  1. Open the Web browser settings.
  2. Select Clear web cache.

This removes temporary website files but keeps cookies/sessions, so you should remain signed in.

Delete all Aniki browser data

Use Delete all browser data only when you intentionally want to reset the browser.

This removes:

  • cookies;
  • saved sessions;
  • history;
  • cache;
  • other Aniki WebView2 profile data.

You will be signed out of websites.

Browser will not open

Aniki Web Browser requires Microsoft Edge WebView2 Runtime.

Most Windows 10/11 systems already have it, but if Aniki reports that WebView2 is missing:

Download Microsoft Edge WebView2 Runtime

Easiest installation

  1. Open the Microsoft page above.
  2. Scroll to Download the WebView2 Runtime.
  3. Under Evergreen Bootstrapper, click Download.
  4. Run the downloaded installer.
  5. Let it finish.
  6. Restart Playnite.
  7. Open Aniki Web Browser again.

The Evergreen Runtime updates automatically, so this is the recommended normal installation.

If the small Bootstrapper cannot download the runtime on your PC, use Microsoft's Evergreen Standalone Installer instead and choose the architecture matching your Windows installation.
