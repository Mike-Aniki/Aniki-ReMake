First Setup Assistant

The Initial Setup assistant is the recommended way to configure Aniki ReMake for the first time.

It gives you sensible starting presets without preventing you from changing individual settings later.

The assistant is available after Aniki Helper is installed and compatible. If the theme is showing an Aniki Helper Required/Update screen instead, complete that requirement first. See Install Aniki ReMake.

Open the assistant

On a new installation

The assistant is offered automatically when Aniki ReMake starts for the first time.

Select Launch assistant.

Open it again later

From the Library or Hub:

  1. Press Start / Menu.
  2. Select Extras.
  3. Select Relaunch setup assistant.

Step 1 — Profile

Choose the name and avatar displayed throughout the theme.

  1. Enter your User name.
  2. Select one of the available avatars.
  3. Continue.

If you leave the name empty, Aniki uses Player.

More avatars and profile options can be changed later in Theme Customization.

Step 2 — Startup

Choose what Aniki should show when Fullscreen starts.

Login screen

Choose:

  • Enabled — show the login screen first.
  • Disabled — go directly to the selected destination.

Startup destination

Choose:

  • Welcome Hub — start on Aniki's home-style Hub.
  • Library — start directly on your games.

Neither choice is permanent.

See Profile & Startup if you want to change this later.

Step 3 — Interface style

The interface presets decide how much information and how many shortcuts are visible.

Clean

A minimal configuration.

It auto-hides the main bars and removes much of the extra information.

Choose this if you mainly want to browse covers with as little interface as possible.

Standard

The normal Aniki ReMake configuration.

This is a good first choice if you do not know what you want yet.

Enhanced

Shows more game information while keeping the interface relatively clean.

Complete

Enables the richest interface, including more panels, shortcuts and integrated information.

These are only presets. Every option can still be changed independently in Settings → Customization.

Step 4 — Theme color

Choose one representative color preset.

The assistant only shows a small selection.

After setup, Theme Customization contains more than 40 presets plus Dynamic Colors.

Pick the one you like visually and continue.

Step 5 — Details layout

Choose how the Game Details screen is arranged.

Available layouts are:

  • Signature
  • Modern
  • Classic
  • Original
  • Showcase
  • Panel

This only changes the presentation. You can switch layouts later without losing game data.

Step 6 — Visual experience

Choose how many animations and visual effects should be active.

Full Animated

Enables all theme animations and visual effects, including animated backgrounds.

Animated

Keeps the main animations but disables animated backgrounds.

Balanced

The recommended balance between appearance and responsiveness.

Performance

Disables the theme's animations and visual effects for the best responsiveness.

Use this on handhelds or lower-end PCs if needed.

Step 7 — Trailers

Choose where trailers can start automatically.

  • Disabled
  • Details only
  • Library and details

If you are unsure, Details only is a good starting point.

Trailer display style can be adjusted later in Theme Customization.

Trailers require compatible video media, normally provided by Extra Metadata Loader.

Step 8 — Optional integrations (Playnite add-ons)

In this guide, integration means an optional Playnite add-on / extension that Aniki can use to provide an extra feature.

The assistant checks which supported add-ons are missing from your Playnite installation.

Choose only the ones you want.

PlayniteAchievements

Adds achievement progress, rarity, trophies and achievement-related views.

UniPlaySong

Adds background music, view music and the integrated Music Player.

Extra Metadata Loader

Provides logos, trailers, videos and other extra media used by the theme.

The assistant also handles the Extra Metadata Fullscreen Mode Helper when required.

Screenshot provider

Choose one:

  • Screenshots Visualizer
  • Screenshot Utilities

If Screenshot Utilities requires its Local Provider, the assistant can offer that too.

AudioSwitcher

Lets Aniki expose audio-device switching in its menus and Overlay.

Custom Fade Animations (CustomFadeAnim)

Adds customizable transitions between game backgrounds, including fades, blur/zoom effects and other animation styles.

Step 9 — Discover Aniki Helper

The assistant introduces the main Helper features such as:

  • Steam connection;
  • game Splash Screens;
  • In-Game Overlay;
  • virtual keyboard;
  • Gamepad Mouse;
  • captures.

You do not need to configure them immediately.

The complete settings are available later from Playnite Desktop mode.

Step 10 — Apply settings

Review your choices.

If you selected missing integrations, the assistant queues them for installation.

  1. Select Apply settings or Apply and install.
  2. If you selected missing integrations, the assistant opens the installation sequence and handles them one at a time.
  3. Install the first extension.
  4. When Playnite asks whether you want to restart, choose No if more extensions are still waiting.
  5. Return to the setup installation window and select Continue to the next extension.
  6. Repeat until you reach the last extension.
  7. After installing the last extension, choose Yes when Playnite asks to restart.

This avoids restarting Playnite after every single extension.

After the final restart, open the settings of any third-party extension that still needs its own configuration.

Change something later

Nothing in the assistant is permanent.

Use:

  • Menu → Settings → Customization for visual/theme settings.
  • Playnite Desktop F9 → Extension settings → Generic → Aniki Helper for complete Helper settings.
  • Menu → Extras → Relaunch setup assistant if you prefer to rerun the presets.
