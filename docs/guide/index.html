Aniki ReMake User Guide

Welcome to the Aniki ReMake user guide.

This guide is written as a practical manual: it explains where to go, what to press, what to change, and what result to expect.

You do not need to read everything in order. Start with the section that matches what you are trying to do.

The main guide assumes you already know the basic idea of Playnite. If you do not, start with New to Playnite? first.

This revision was reviewed against Aniki ReMake 3.4.3, Aniki Helper 1.5.7, and the current Playnite 10 user interface/source provided for this guide.

Curious how Aniki ReMake was created?

Aniki ReMake grew from earlier Playnite theme experiments into the larger console-style project it is today.

If you want to know where it started, how Aniki Remix led to ReMake, and why Aniki Helper became such an important part of the project, read:

The Story is a separate page on the Aniki ReMake website. You do not need to read it to configure the theme.

What does “integration” mean?

Throughout this guide, an integration is basically an optional Playnite add-on / extension that Aniki can use to add or expose extra features.

Examples include achievement, music, screenshot, audio-switching and background-transition add-ons.

Two settings areas you should know

Aniki ReMake has two main configuration areas.

Theme Customization

Use Theme Customization when you want to change how Aniki looks.

From Aniki Fullscreen:

  1. Press Start / Menu to open Quick Access.
  2. Select Settings.
  3. Select Customization.

You will find categories such as Appearance, Interface, Main View, Details View, Covers, Backgrounds and Videos, and Achievements.

Aniki Helper

Use Aniki Helper when you want to change what Aniki does.

For the complete settings interface, use Playnite Desktop mode:

  1. Open Playnite in Desktop mode.
  2. Click the Playnite icon in the top-left corner.
  3. Select Add-ons... or press F9.
  4. In the left column, open Extension settings → Generic.
  5. Select Aniki Helper.

The top tabs are:

  • Home
  • Theme features
  • Steam
  • Exclusive Features
  • Video Center
  • Advanced
Simple rule: if you are changing the visual presentation, start in Theme Customization. If you are configuring a feature or integration, start in Aniki Helper.
