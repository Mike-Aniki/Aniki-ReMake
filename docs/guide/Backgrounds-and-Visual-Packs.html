Backgrounds & Visual Packs

Aniki lets you decide what should appear behind the Library.

A Visual Pack and a Library background source are related, but they are not the same setting.

Open Background settings

  1. Press Start / Menu.
  2. Open Settings.
  3. Open Customization.
  4. Select Backgrounds and Videos.

Use each game's normal background

  1. Find Main library background.
  2. Select the game-background option.
  3. Return to the Library.
  4. Move between games and confirm the background changes with the selected game.

This is the normal choice if your Playnite backgrounds are already well curated.

Use Visual Pack backgrounds

First select the pack:

  1. Open Customization → Appearance.
  2. Select Choose background visual pack.
  3. Pick the pack you want.

Then tell the Library to use it:

  1. Open Backgrounds and Videos.
  2. Change Main library background to the Visual Pack source.
  3. Return to the Library.

Use Visual Pack backgrounds in the Library but game backgrounds in Details

This is a common mixed setup.

  1. Set Main library background to Visual Pack.
  2. Enable Show game background in details view.
  3. Return to the Library.
  4. Open a game with A.

The Library keeps the consistent Visual Pack presentation, while Game Details uses the selected game's own artwork.

Use the current filter as the background

If you maintain custom filter backgrounds:

  1. Set Main library background to the filter-background mode.
  2. Configure your custom filter background folder in Aniki Helper.
  3. Make sure the filenames match the Playnite filter preset names.

See Covers, Banners & Custom Assets for the custom-folder procedure.

Use no background

Set Main library background to the no-background option.

Use this if you want the most static/minimal presentation or do not want artwork changing while browsing.

Background images are cropped too much

Aniki normally preserves aspect ratio and crops where necessary.

If your images use unusual dimensions:

  1. Open Backgrounds and Videos.
  2. Test Stretch backgrounds to fill the screen.

This can reduce cropping, but it can also distort non-16:9 images.

Leave it disabled if the normal behavior already looks correct.

SteamGridDB Hero images do not fit well

Enable SteamGridDB Hero compatibility mode.

This changes the fitting behavior so the full Hero image can remain visible with less zoom/cropping.

Use it only if your background collection is actually based around that format.

Animate backgrounds

Enable Animate game backgrounds for a slow background zoom.

Disable it if:

  • you prefer static artwork;
  • you want to reduce motion;
  • you are optimizing performance.

Trailers

Trailer controls are on the same Backgrounds and Videos page.

For the complete setup, see Logos & Trailers.
