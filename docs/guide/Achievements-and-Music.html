Achievements & Music

Two optional integrations provide major parts of the complete Aniki experience:

  • PlayniteAchievements for achievement data;
  • UniPlaySong for music.

Install only the feature you want.

Quick setup — Achievements

  1. Install PlayniteAchievements from F9 → Browse → Generic if it is not already installed.
  2. Configure PlayniteAchievements in its own settings and let it obtain achievement data for your games.
  3. Switch to Aniki Fullscreen and open Start / Menu → Achievements.
  4. If you want to change Aniki's presentation, open Settings → Customization → Achievements.
If achievement data is already visible, the integration is working. Cache rebuild and per-game refresh actions below are repair tools, not required first-time steps.

Achievements — install PlayniteAchievements

If it was not installed by Initial Setup:

  1. Open Playnite Desktop.
  2. Press F9.
  3. Open Browse → Generic.
  4. Search for PlayniteAchievements.
  5. Install it.
  6. Save and restart if requested.
  7. Configure PlayniteAchievements using its own settings.

Open Achievements in Aniki

Once the integration has data:

  1. Press Start / Menu.
  2. Select Achievements.

Achievement information can also appear in the Library, Details view, Profile and Hub depending on your theme settings.

Change how achievements are displayed

  1. Open Fullscreen.
  2. Press Start / Menu.
  3. Open Settings → Customization.
  4. Open Achievements.

You can configure options such as:

  • Gamerscore vs achievement level;
  • game logo vs title in the achievement view;
  • hidden achievements shown by default;
  • 24-hour achievement timestamps.

Rebuild Achievement Memories

If recent achievement memories, icons or rarity data are missing/outdated:

  1. Open Playnite Desktop.
  2. Press F9.
  3. Open Extension settings → Generic → Aniki Helper.
  4. Open Theme features → Gallery & achievements.
  5. Find Achievement Memories Cache.
  6. Click Rebuild cache.
  7. Wait for it to finish.

Refresh achievements for one game

Fullscreen

  1. Select the game.
  2. Press Y.
  3. Open Extensions → Aniki Helper → Achievements Memories.
  4. Select Refresh this game's memories.

Desktop

  1. Right-click the game.
  2. Open Aniki Helper → Achievements Memories.
  3. Refresh the game.

Use this when only one game's data is wrong.

Quick setup — Music

  1. Install UniPlaySong from F9 → Browse → Generic if it is not already installed.
  2. Configure your music behavior inside UniPlaySong's own settings.
  3. Switch to Aniki Fullscreen and open Start / Menu → Extras → Music Player.
  4. If you also use Aniki Splash Screens, optionally enable Pause UniPlaySong while splash screen is visible.
If music plays and the Music Player opens correctly, the basic integration is complete.

Music — install UniPlaySong

If it was not installed during Initial Setup:

  1. Open Playnite Desktop.
  2. Press F9.
  3. Open Browse → Generic.
  4. Search for UniPlaySong.
  5. Install it.
  6. Configure UniPlaySong using its own settings.
  7. Restart if requested.

Open the Music Player

From Fullscreen:

  1. Press Start / Menu.
  2. Select Extras.
  3. Select Music Player.

You can also assign Music Player to a Hub Features & Apps slot.

The Music Player is available only when UniPlaySong is installed.

Avoid duplicate event sounds

Aniki Helper can play theme event sounds itself.

If another audio extension also plays the same interface/event sounds, disable one set to avoid duplicates.

Aniki Helper's setting is in:

Theme features → Sounds & Sequences → Event sounds

Pause music during game Splash Screens

If you use UniPlaySong:

  1. Open Aniki Helper Desktop settings.
  2. Open Exclusive Features → Splash screen.
  3. Enable Pause UniPlaySong while splash screen is visible.
  4. Save.

Aniki resumes the music when the splash closes.
