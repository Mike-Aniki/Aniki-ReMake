Backup, Reset & Diagnostics

Aniki Helper includes tools for theme configuration backups, Monthly Stats backups, resetting settings and creating useful debug logs.

Open:

Playnite Desktop → F9 → Extension settings → Generic → Aniki Helper → Advanced

Back up the theme configuration

  1. Open Advanced → Backup and restore.
  2. Select Export theme configuration.
  3. Choose where to save the backup.
  4. Keep the file somewhere safe.

Use this before major theme-setting changes or when moving/reinstalling your setup.

Restore a theme configuration

  1. Open Advanced → Backup and restore.
  2. Select Import theme configuration.
  3. Choose your previous backup.
  4. Apply the configuration.
  5. Restart/reopen Fullscreen if requested.

Back up Monthly Stats

Monthly Stats have a separate backup.

  1. Open Advanced → Backup and restore.
  2. Find the Monthly statistics section.
  3. Select Export Monthly Stats.
  4. Save the JSON backup.

This backup contains Monthly Stats only.

It does not back up your Steam account, games, plugins or media.

Restore Monthly Stats

  1. Open the same Monthly statistics section.
  2. Select Import Monthly Stats.
  3. Choose the exported backup.
  4. Confirm.

Delete all Monthly Stats

Use this only when you intentionally want to erase Aniki Helper's monthly tracking history.

  1. Export a backup first if you may need the data later.
  2. Click Delete all Monthly Stats.
  3. Confirm the warning.

Tracking restarts from that moment.

Restore Aniki Helper defaults

Use the Helper reset when you changed many plugin options and want a clean configuration.

  1. Open Advanced → Backup and restore.
  2. Find the reset/defaults action.
  3. Read the warning.
  4. Confirm.

The reset is designed to restore Aniki Helper settings without treating unrelated user content as disposable.

If your problem is only one feature, fix that feature first instead of resetting everything.

Create a clean debug log

When reporting an Aniki Helper bug:

  1. Open Advanced → Diagnostics.
  2. Clear the existing log.
  3. Enable Debug Mode / debug logs.
  4. Reproduce the problem once.
  5. Open the Playnite logs folder.
  6. Send extensions.log with your report.
  7. Disable Debug Mode afterward.

A short clean log is much easier to diagnose than a log containing hours of unrelated activity.

When to use Diagnostics

Use Debug Mode when:

  • the developer asks for it;
  • a bug is reproducible;
  • normal settings checks did not explain the problem.

Do not leave verbose debug logging enabled permanently without a reason.
