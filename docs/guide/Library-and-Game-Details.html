Library & Game Details

This page explains how to change how much information Aniki shows while browsing your games and on the Game Details screen.

Open the relevant settings

  1. From Aniki Fullscreen, press Start / Menu.
  2. Open Settings.
  3. Open Customization.

Use:

  • Interface for the top/bottom bars and shortcut buttons.
  • Main View for Library information and visual effects.
  • Details View for the Game Details screen.

Make the Library cleaner

Auto-hide navigation bars

  1. Open Interface.
  2. Enable Auto-hide top button bar.
  3. Enable Auto-hide bottom filter bar if desired.
  4. Return to the Library and navigate toward the top/bottom to confirm the bars still appear when needed.

Auto-hide keeps the controls available.

Do not confuse it with the options that completely disable the bars.

Remove the top or bottom bars completely

If you use controller shortcuts and do not want the bars at all:

  1. Open Interface.
  2. Enable Disable center top bar buttons and/or Disable bottom filter bar.
  3. Test navigation before leaving the settings.

If you remove a navigation element, make sure you know the corresponding controller shortcut first.

Choose which top-bar shortcuts are shown

Still in Interface, you can decide which optional shortcuts appear in the top bar.

Depending on your installed integrations, Aniki can expose shortcuts such as:

  • Tools;
  • Extensions;
  • Achievements;
  • Steam Friends;
  • Music Player;
  • Overlay and other supported feature shortcuts.
  1. Open Interface.
  2. Enable the shortcuts you actually use.
  3. Disable the ones you do not need.
  4. Return to the Library and check the top bar.

A shortcut may still depend on its corresponding feature/integration being available.

Choose how game information is displayed in the Library

Open Main View.

Aniki provides several information styles.

Controller Shortcut Bar

Shows the controller actions around/below the game list.

Enable this if you want the controls to remain visible while learning the theme.

Compact Game Info Bar

Shows a smaller information bar above the covers.

Use this if you want game information but less visual clutter.

Detailed Side Info Panel

Shows richer game information on the right side.

Use this if you like a more information-heavy Library.

Some modes disable incompatible modes automatically to avoid overlapping layouts.

Hide individual Library information

Still in Main View, find Displayed Information.

Turn off only the items you do not use, such as:

  • source logo;
  • favorite badge;
  • age rating;
  • game description;
  • achievement badge;
  • filtered game count.

This is usually better than choosing a completely different theme preset just to hide one item.

Feature icons come from Playnite metadata

If your current layout shows game-feature icons, Aniki reads the game's Features field from Playnite.

If an icon is missing:

  1. Open Playnite Desktop.
  2. Right-click the game.
  3. Select Edit.
  4. Check Features.
  5. Add/correct the missing feature.
  6. Save.

See Artwork & Metadata for more information.

Change Library visual effects

Open Main View → Visual Effects.

You can control effects such as:

  • dimming the background when the top bar is focused;
  • dimming the background when the filter bar is focused;
  • game-logo animation;
  • left/bottom dark fades.

If text becomes hard to read over bright artwork, increase the relevant dark fade instead of immediately changing the artwork.

Customize Game Details

Open Details View.

First choose the layout from:

Customization → Appearance → Choose details view layout

Then use Details View to fine-tune it.

You can change things such as:

  • opening animation;
  • status bar visibility;
  • status bar position;
  • status bar opacity;
  • information panel animations;
  • layout-specific cover/panel presentation.

Hide metadata from Game Details

The Displayed information section lets you hide individual fields.

Examples include:

  • source;
  • genre;
  • category;
  • HowLongToBeat;
  • release year;
  • playtime;
  • last activity;
  • install size;
  • completion status;
  • rating;
  • achievements;
  • current players.

Example: simple Details page

Keep the title/logo, genre, playtime, completion status and achievements, then hide fields you never use.

Example: information-heavy Details page

Keep HLTB, install size, activity, rating, achievements and player count visible.

These examples are only starting points; the settings work independently.

Add or remove the frame behind the game list

Open Covers if you want a stronger framed look around the cover list.

  1. Enable Show game list frame background.
  2. Adjust Game list frame opacity.
  3. Return to the Library and check the result.

Disable the frame if you prefer the covers to sit directly over the main background.

Navigation feels slower after enabling effects

Change one thing at a time:

  1. disable animated backgrounds;
  2. disable cover reflection;
  3. disable animated cover border;
  4. reduce automatic trailers;
  5. use Performance Mode if you still need more headroom.

Testing one setting at a time makes it easier to identify what actually affects your system.

For a complete performance checklist, see Performance & Recommended Settings.
