Dynamic Colors, News & Statistics

These Aniki Helper features normally work in the background, but this page explains how to configure or repair them.

Dynamic Colors

Dynamic Colors generates an Aniki color palette from the selected game's artwork.

Enable Dynamic Colors

  1. Open Aniki Fullscreen.
  2. Press Start / Menu.
  3. Open Settings → Customization → Appearance.
  4. Select Choose theme color.
  5. Choose Dynamic Colors.
  6. Apply/restart if requested.

Which image does Dynamic Colors use?

The current Aniki Helper tries to use the game's Playnite Background Image first.

If no usable background is available, it can fall back to the game's Cover Image.

Supported image extensions include:

  • JPG / JPEG
  • PNG
  • BMP
  • WEBP

Very small images can be ignored; use normal game artwork rather than tiny thumbnails.

Older Aniki guides described an ExtraMetadata-folder-only system. That is no longer the current behavior.

Pre-load Dynamic Colors

To prepare colors before you browse the games:

  1. Open Playnite Desktop.
  2. Press F9.
  3. Open Extension settings → Generic → Aniki Helper.
  4. Open Advanced → Color processing.
  5. Enable Pre-load colors in background.
  6. Save.

This lets Aniki analyze artwork in the background and reuse the cached palette later.

It can make color changes feel more immediate while navigating.

On a very low-end system, background color analysis itself may briefly use resources, so test whether pre-loading helps your setup.

Dynamic Colors do not change

Check:

  1. Does the game have a Playnite Background Image?
  2. If not, does it have a usable Cover Image?
  3. Is the image a supported format?
  4. Is it a normal-size artwork file rather than a tiny thumbnail?
  5. Is Dynamic Colors selected as the Theme Color?

If you recently replaced artwork, reset the cache.

Reset the Dynamic Colors cache

Use this after replacing many backgrounds/covers or when colors are clearly stale.

  1. Open Aniki Helper → Advanced → Color processing.
  2. Use the color-cache reset action.
  3. Let Aniki rebuild the palettes.

Do not reset a working cache routinely.

Aniki News

Open:

Aniki Helper → Theme features → News

Enable or disable News

  1. Enable News if you want Aniki Helper to fetch articles.
  2. Disable it if you do not use the feature.
  3. Save.

When disabled, Aniki stops the News scanning/loading work.

Use custom RSS feeds

The current News settings support configurable sources.

For a source:

  1. enter the display name;
  2. enter the RSS feed URL;
  3. save.

An empty/invalid feed can fall back to Aniki's default source behavior.

Reset one News source cache

Use a source-specific cache reset only when that source is clearly stuck or outdated.

  1. Open Theme features → News.
  2. Find the affected source.
  3. Use its reset-cache action.
  4. Confirm.

You normally do not need to clear the cache every time you edit a URL.

Library statistics

Open:

Aniki Helper → Theme features → Statistics

Aniki uses library data for Profile/Hub statistics.

You can choose whether hidden games are included.

Monthly statistics

Aniki Helper keeps monthly tracking data used for information such as:

  • playtime this month;
  • games played this month;
  • most played game.

Monthly Stats can be exported/imported from Advanced backup settings.

If the data is wrong or you intentionally want to start over, use the monthly reset/delete tools only after considering a backup.

See Backup, Reset & Diagnostics.
