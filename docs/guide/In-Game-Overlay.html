In-Game Overlay

The Aniki In-Game Overlay displays a controller-friendly quick-action panel above the game you are currently playing.

It is a normal transparent Windows window; it is not injected into the game like Steam or Discord overlays.

Open Overlay settings

  1. Open Playnite Desktop.
  2. Press F9.
  3. Open Extension settings → Generic → Aniki Helper.
  4. Open Exclusive Features.
  5. Select In-game overlay.

Enable the Overlay

  1. Enable In-game overlay.
  2. Choose a Controller shortcut.
  3. Optionally choose a keyboard shortcut.
  4. Save.

Controller options include:

  • Start + Back
  • Back + Y
  • Guide button
  • Disabled

Restart Playnite after changing the keyboard hotkey.

Choose a controller shortcut

Start + Back

A good choice if the Guide button is already used by Windows, Steam or another controller tool.

Back + Y

Use this if it does not conflict with your games or other shortcuts.

Guide button

Convenient when it works on your system, but Windows, Steam, Xbox Game Bar or controller tools can intercept it.

If it is unreliable, choose another shortcut.

Use the Overlay in a game

  1. Launch a game from Aniki.
  2. Wait until the game is running.
  3. Press your configured Overlay shortcut.
  4. Use the Overlay controls.
  5. Resume/close the Overlay to return to the game.

Prevent the game from reacting to Overlay inputs

By default, the game keeps running while the Overlay is open.

If controller presses are affecting both the Overlay and the game, you can use:

Suspend game while overlay is open

This temporarily freezes the game process while the Overlay is displayed.

When not to use Suspend

Do not use process suspension with:

  • online games;
  • multiplayer games;
  • anti-cheat protected games;
  • games running as administrator.

For those games, keep Default: Do nothing or create a per-game exception.

Never suspend one game

Fullscreen

  1. Select the game.
  2. Press Y.
  3. Open Extensions → Aniki Helper → Overlay Settings.
  4. Select Never suspend this game.

Desktop

  1. Right-click the game.
  2. Open Aniki Helper → Overlay Settings.
  3. Select Never suspend this game.

The game is added to the Overlay exception list.

Remove an exception

Either:

  • open the game's Overlay Settings action again and allow suspension; or
  • open the Overlay settings page and remove/uncheck the game from Never suspend games.

You can also clear the full list from the settings page.

Overlay does not appear

The Overlay works best with:

  • borderless fullscreen;
  • windowed fullscreen;
  • windowed games.

Possible problem cases include:

  • exclusive fullscreen;
  • anti-cheat;
  • elevated/admin game processes;
  • another application forcing itself above the Overlay.

Try borderless/windowed fullscreen first.
