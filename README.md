## About Aniki ReMake

**Aniki ReMake** is a highly customizable Fullscreen theme for [Playnite](https://playnite.link/), designed to turn a PC game library into a polished console-style experience.

It is built for controller navigation, televisions, and living-room setups. The theme combines clean library layouts, immersive media, secondary views, game information, achievements, captures, music, Steam integrations, and extensive visual customization.

Aniki ReMake works together with **[Aniki Helper](https://github.com/Mike-Aniki/AnikiHelper)**, its dedicated companion plugin. Aniki Helper provides systems that a theme cannot handle alone, including advanced menus, notifications, dynamic colors, splash screens, Steam features, library statistics, and the in-game overlay.

---

## Highlights

| | |
|---|---|
| **Controller-first interface** | Designed for Fullscreen navigation from a couch, TV, or handheld PC. |
| **Multiple library layouts** | Choose between different cover formats, information panels, bars, and visual styles. |
| **Home and secondary views** | Access your library activity, statistics, captures, achievements, news, store pages, applications, and more. |
| **Deep media integration** | Use covers, backgrounds, logos, trailers, game music, screenshots, and custom splash screens. |
| **Steam features** | Display friends, wishlist content, personalized recommendations, events, updates, and other Steam data through Aniki Helper. |
| **Achievements and captures** | Integrates with supported achievement and screenshot plugins across the library, details views, Hub, notifications, and overlay. |
| **In-game overlay** | Return to the game, close it, browse current-game information, view achievements and captures, and use supported overlay features. |
| **Extensive customization** | Configure colors, avatars, visual packs, fonts, corners, banners, information blocks, animations, menus, and navigation behavior. |

Most integrations are optional. You can keep Aniki ReMake simple or enable the advanced systems that match your setup.

## Requirements

Before installing Aniki ReMake, make sure that you have:

- the latest stable version of [Playnite](https://playnite.link/);
- Windows 10 or Windows 11;
- the latest available version of [Aniki Helper](https://playnite.link/addons.html#AnikiHelper_96a983a3-3f13-4dce-a474-4052b718bb52);
- any optional extensions required by the features you want to use.

Always update **Playnite first**, restart it, and then update Aniki Helper, integrated plugins, and Aniki ReMake.

For the complete installation procedure, use the **[Beginner Guide](https://github.com/Mike-Aniki/Aniki-ReMake/wiki/Beginner-Guide)**.
